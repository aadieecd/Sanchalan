# Sanchalan — Event Operations Command Center

An intelligent event operations platform designed to help student clubs, campus fests, hackathons, and event teams coordinate their work from one place.

## Overview

Sanchalan aims to simplify event planning and team coordination by bringing event operations, task tracking, and team workflows into a centralized workspace.

Built as a hackathon project, it explores how connected tools and AI-assisted workflows can make organizing events more efficient.

## Key Features

- **Event Coordination** — Organize event-related information in one workspace.
- **Team Operations** — Support collaboration and task coordination.
- **Centralized Workspace** — Keep essential event information accessible.
- **Notion Integration** — Connect event workflows with Notion where configured.
- **AI-Assisted Workflows** — Explore AI-powered assistance where implemented.

*Note: The features available depend on the current implementation and configured integrations.*

## Technology Stack

- React
- TypeScript
- Vite
- Notion API
- Vercel for deployment

## Getting Started

### Prerequisites

- Node.js and npm
- Git

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/adoreraditya/Sanchalan.git
   ```

2. Enter the project directory:

   ```bash
   cd Sanchalan
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Configure any required environment variables using the project's setup instructions. Keep API keys and tokens private.

5. Start the development server:

   ```bash
   npm run dev
   ```

6. Open the local URL displayed in your terminal.
